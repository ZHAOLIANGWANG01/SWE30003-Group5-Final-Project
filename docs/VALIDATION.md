## 验证边界

存储层测试会直接构造状态和排班记录以验证持久化，不能作为合法业务流程的证明。并发分配测试使用示例业务检查来验证数据库锁的串行化能力，不表示 C 的排班业务已经开发完成。

B/C 仍必须补齐所有业务规则、页面和完整业务演示。最终作业要提供正常输入、错误验证、修改/删除输入、成功结果等证据，不能用当前登录截图代替四个业务领域的演示。
